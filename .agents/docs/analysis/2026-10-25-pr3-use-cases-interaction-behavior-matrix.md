## 1. Command census and two-mode contracts

Local mode is **repo-local .backlog JSON** (UUID, branch priority, manifest/archive, versioned config), C:src/schema.js:1-57; C:src/commands.js:4-15. Shared mode is **one external Git repo** (Markdown phases/archive source, SQLite mirror and event history, per-agent seen cache, commits pushed to backlog origin/main), C:src/shared/{store.js:57-95,db.js:25-59,sync.js:389-482}. The identical word update has deliberately different meaning: local updates the CLI installation, shared updates an item (C:src/main.js:23-46). Local JSON result is enveloped in ok/data; shared JSON returns oracle-shaped content. Error codes shared: 0 success, 1 business refusal, 2 wrong arguments/environment, 3 sync failure **or pop idle**, 4 missing home, 5 stale view, C:src/help.js:7-24.
