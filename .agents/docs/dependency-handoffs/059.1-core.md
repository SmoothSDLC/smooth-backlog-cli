# 059.1 hand-off core - dependency hand-offs for its dependents 68, 69, 70, 71 and 73

The earlier hand-off blocks for 064, 065 and 066 (now archived; the later slices were re-split to run in
parallel, lead note 2026-10-30) are superseded by these five blocks, which carry the lead's design
amendment of 2026-10-30 (records and receipts stored as compact JSON strings in the front-matter lists).
This revision (source commit c9b9e5a, review round 2) supersedes the 0ae8642 revision: a present but
empty handoffs key is missing, not the legacy mark; a record or receipt without a digest no longer
satisfies the edge; the body blocks match the method document (SOURCE_COMMIT ; BRANCH on the record,
the method's receipt field names, no END line on the receipt).

the PRODUCER_AGENT line, and REVIEW is the given review or 'pending'.
