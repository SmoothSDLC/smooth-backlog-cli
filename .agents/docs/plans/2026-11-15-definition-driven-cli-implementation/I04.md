## Session 1: integrate (at most 30 minutes)

This slice joins slices that were built and reviewed on their own. Work only from this file.

1. Load the skills: `verification-before-completion`, `systematic-debugging`, `requesting-code-review`, `ponytail`.
2. `git fetch` and `git switch -c slice/I04 origin/simplify/pr3-review` (the slices of "Depends on" are merged there).
3. Run every scenario and test of "Checks". For each failure, find where two slices disagree (a name, a shape, an order) with `systematic-debugging`, and fix it at that seam only; never rewrite a slice.
4. Write any scenario of "Scenarios" that no slice wrote yet.
5. Run `npm test`, `npm run check` and the guard; then `requesting-code-review` and `ponytail` over the seams changed; commit `I04: Integration: every user command`.
6. Write the hand-off (the same form as a build slice, with "Seams fixed" in place of "Unit tests").
